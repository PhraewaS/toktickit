## Performance-smoke definition

`PERF-04` is a repeatable smoke guard, not a production benchmark. Against the deterministic Lab 4 local seed, issue 10 sequential requests for each dashboard endpoint and both role-appropriate Action Taken list endpoints. The test verifies dashboard lists stay capped, Action Taken lists stay within the fixed seed's expected bound, and requests do not return Ticket collections. Each request must complete within 1 second in the configured local environment. Record request count, maximum duration, and failure count. A slower environment is reported as evidence rather than silently changing the threshold.
